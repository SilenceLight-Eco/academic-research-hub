# 学术研究工作台 · Academic Research Hub

一个面向个人研究者的浏览器优先学术工作台：把待办、论文进度、学术履历、知识库、笔记、提示词、研究项目、数据与代码、文献管理和专注计时放在同一个地方。

**在线使用：**[打开浏览器版](https://silencelight-eco.github.io/academic-research-hub/)（如果暂时无法访问，请查看仓库 **Settings → Pages** 中显示的实际地址。）

## 开始使用

1. 打开浏览器版，点击右上角“登录同步”。
2. 使用邮箱创建账号，并按提示完成邮箱验证；之后即可登录。
3. 在“概览”里设置入学日期、预计毕业日期和毕业论文要求，再从左侧进入其他模块。

登录账号后，工作台数据保存在云端账号中，可在不同设备登录同一账号继续使用。登录、注册和密码重置需要网络连接。

## 功能一览

| 模块 | 用途 |
| --- | --- |
| 概览 | 查看学业进度、毕业论文完成情况；登记已发表论文，并集中查看基金项目、学术获奖和学术会议。 |
| 待办 | 记录任务、优先级和截止时间。 |
| 论文管线 | 跟踪研究想法、论文写作与投稿流程。 |
| 学术履历 | 按类别登记基金、获奖和会议；会议可记录名称、地点、时间及报告论文。 |
| 知识库 | 管理文件夹和 Markdown 文档；支持所见即所得编辑、标题大纲、文字颜色、排序、版本记录和回收站。 |
| 笔记 | 用 Markdown 写作，实时预览公众号排版；支持主题样式、复制排版内容、版本记录和回收站。 |
| 提示词 | 分类保存提示词，填写模板变量后复制使用。 |
| 研究项目 | 管理目标、分类、状态、进度、成员、里程碑和关联资源。 |
| 数据与代码 | 归档数据集、分析代码和复现包，记录版本、来源、环境、变量、运行顺序及复现检查。 |
| 文献与引用 | 管理文献信息、DOI、标签、阅读笔记和关联项目；支持 BibTeX 导入、引用预览与复制。 |
| 专注 | 使用专注计时器并回顾近期专注记录。 |

工作台提供多种整体主题。各内容模块还提供自动保存、版本记录或回收站等保护功能，具体能力以模块内选项为准。

## 自动保存、同步与备份

- 编辑内容每 3 分钟自动保存；离开页面时，若仍有未保存更改，会提示处理。
- 云端内容按账号同步到其他设备。如果同一账号的本机与云端版本发生冲突，页面会提供选择，并在覆盖前保存冲突副本。
- 点击顶部“数据备份”可导出或恢复账号数据。备份文件可能包含个人研究内容，请妥善保管。
- 点击右上角账号可修改密码或退出登录；修改密码前需要验证当前密码，忘记密码可通过邮箱重置。

## 飞书文档联动

知识库文档和公众号笔记可以保存已有飞书文档链接并直接打开。也可以把内容导出为一份新的飞书文档，导出后的链接会保存回对应条目并参与工作台账号同步。

飞书导出需要部署 Supabase Edge Function，并在服务端配置飞书自建应用凭据；**仓库中的浏览器代码不保存飞书应用密钥**。再次导出会新建文档，目前不是对已有飞书文档的双向实时同步。配置步骤见[飞书联动说明](docs/feishu-integration.md)。

## 本地运行

仓库仍包含本地 Python 服务。若希望在自己的电脑上运行，可在仓库根目录执行：

```bash
python server.py
```

然后在浏览器打开 <http://127.0.0.1:8765>。仓库保留了本地 Python 服务入口，但当前浏览器版的账号和工作区仍通过 Supabase 登录与同步；仅在本机启动服务不会自动切换成纯本地存储或离线模式。不要在没有 HTTPS 和适当安全配置的情况下把本地服务直接公开到互联网。

## 技术与部署说明

- 浏览器版由静态 HTML、CSS 和 JavaScript 构成，账号与云端工作区通过 Supabase 提供的 Auth 和数据库接口连接。
- 仓库根目录的 `index.html` 是网页入口；GitHub Pages 的实际访问地址以仓库 **Settings → Pages** 为准。
- 若要部署一套独立的在线实例，需要准备自己的 Supabase 项目并配置认证回调地址和工作区数据表；不要把 Supabase `service_role` 密钥放进前端。
- 当前交付形态是网页和本地 Python 服务，不包含可直接安装的 `.exe` 或 `.apk` 安装包。
