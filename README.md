# 学术研究工作台 · Academic Research Hub

一个面向个人研究者的浏览器优先学术工作台：把待办、论文进度、学术履历、知识库、笔记、提示词、研究项目、数据与代码、文献管理、期刊追踪和专注计时放在同一个地方。

**在线使用：**[打开浏览器版](https://silencelight-eco.github.io/academic-research-hub/)（如果暂时无法访问，请查看仓库 **Settings → Pages** 中显示的实际地址。）

## 开始使用

1. 打开浏览器版，点击右上角“登录同步”。
2. 使用邮箱创建账号，并按提示完成邮箱验证；之后即可登录。
3. 在“概览”里设置入学日期、预计毕业日期和毕业论文要求，再从左侧进入其他模块。

登录账号后，工作台数据保存在云端账号中，可在不同设备登录同一账号继续使用。登录、注册和密码重置需要网络连接。

工作台提供多种整体主题。各内容模块还提供自动保存、版本记录或回收站等保护功能，具体能力以模块内选项为准。

### 娱乐（本地休闲）

左侧点击“娱乐”，选择斗地主、掼蛋、5·10·K、休闲麻将、中国象棋或五子棋。斗地主顶部可切换经典／癞子（切换会重新发牌），先叫分，再点选手牌、使用“提示”并点击“出牌”；连续两人不出后恢复自由出牌。癞子组合可替代非王牌，单张按本值；王炸、纯癞子炸、硬炸、软炸依次递减。同一组手牌有多种合法解释时，可在“出牌方式”中选择，牌桌和记录显示实际采用的解释。

掼蛋和 5·10·K 均为双副牌四人固定搭档休闲版，每人 27 张，你与电脑 2 搭档。掼蛋可选择级牌，红桃级牌百搭，支持固定五张顺子、三连对、钢板、同花顺、4 至 10 张炸弹、四王与对家接风；每局独立，按头游方判胜，暂不提供跨局升级、进贡或还贡。5·10·K 提供杂花／同花五十K、同点炸弹与四王，按 5、10、K 分别计 5、10、10 分，全局 200 分；每圈最后出牌方抓取桌面分，三家出完后末家剩余分牌给头游方，分高方胜，平分时头游方胜。具体牌型顺序和与地方规则的差异在游戏内展开查看，不宣称等同完整赛事规则。癞子规则参考[波克官方说明](https://www.pook.com/games/lzddz.html)，掼蛋牌型参考[国家体育总局介绍](https://www.sport.gov.cn/n20001280/n20745751/n20767274/c22011669/content.html)。

象棋、五子棋可切换人机或本机双人模式，切换模式会重新开局；象棋先选棋子，再点可走位置，五子棋直接点击空位。两种棋类均提供休闲／标准电脑难度，修改难度不清空棋局，下次电脑行动生效。

休闲麻将由你对阵三位电脑，采用 108 张万、筒、条的三门无字规则。点击选牌，再点击“打出”；可使用理牌提示，遇到可响应的弃牌会出现碰、明杠、胡牌或跳过按钮，持有四张相同牌可暗杠，杠后自动补牌。支持四组面子加一对将、未副露七对；胡牌优先，多家可胡按出牌者之后的顺序取第一家。此版本不吃牌、不加杠、不抢杠、不计番，牌墙耗尽流局，不等同于国标、四川或广东等完整地方规则。各家弃牌和对局记录可展开查看。

游戏逻辑在浏览器本地运行，不使用 AI 服务、账号凭证或学术资料，也不新建云端表。切换模块、游戏或将页面放入后台时暂停电脑行动；回到相应游戏后续玩。本次页面中的对局会保留，但刷新、关闭网页后重新开局，不参与云端同步。象棋为休闲规则，不包含竞赛级长将长捉裁定，具体规则可在游戏中展开查看。

### 返修论文（独立工作区）

进入“论文管线”，在内部导航的“在投论文”和“已发表论文”之间点击“返修论文”。这里集中展示返修截止日期、审稿意见与回复、处理进度、待办联动、清单导出和各轮材料。原“在投论文”保留投稿管理及“进入返修论文／查看本轮返修”入口，不再重复展开返修编辑区。

大修改、小修改及已保存清单／材料的论文自动显示，可筛选“当前返修中”“历史与归档”，也可搜索论文、期刊或返修意见。要开始一篇论文的返修，从上方选择现有在投论文并点击“开始返修”（尚非返修状态时设为“大修改”，可再选“小修改”）。该操作沿用原论文和当前投稿记录，不复制卡片或增加投稿次数；请先在原记录填写当前期刊。

已有数据不需要手动迁移。返修意见仍按原账号、论文和投稿轮次保存；删除投稿历史后保留的清单及已发表论文的返修归档，也在此工作区查看。“查看原论文／投稿记录”可返回原卡片。

### 按审稿人分组

每轮返修清单预置“编辑”“审稿人 1”“审稿人 2”分组，组标题可展开／折叠，并分别显示完成数量和比例；总进度仍统计全部意见。已有意见保留在“未分组”，不自动推断审稿人。可在意见的“意见来源”下拉框中更换分组，或直接点击组内“新建本组意见”。

在清单底部填写名称并点击“新建分组”，可添加更多审稿人。展开分组后可修改名称并点击“重命名”，也可删除分组；删除时只将组内意见移到“未分组”，不删除意见、回复或关联待办。默认分组同样可以重命名／删除，删除后刷新不会恢复。名称限 1 至 40 个字符，同轮不可重名；“未分组”是保底归类，不支持删除。

分组按投稿轮次独立保存，重投时使用新一轮的默认分组，旧分组与回复保留在原轮次。分组和移动意见不改变其稳定编号或待办关联；从待办返回时会展开对应分组并定位意见。Markdown 回复清单也会按分组导出，保留原意见序号与各组完成进度。

### 返修提交前检查

在每轮返修清单下点击“提交前检查”，可集中查看未完成意见、空白回复、本轮缺失材料和未确认材料；没有登记任何意见也不会显示通过。“定位意见”可展开对应审稿人分组并聚焦状态或回复字段，“查看材料”可打开本轮对应分类。检查不会修改意见状态、写入检查结果或替你提交。

材料检查仅在登录后按需读取“返修稿”“回复信”两个私有分类的附件元数据，不下载正文，不轮询。确认分类下没有附件才标为缺失；未登录、离线、权限／网络错误或缺少可靠轮次关联均标为“未确认”，不会误报通过。通用附件和旧轮次文件不会自动算入；旧归档若缺少关联，需要人工在材料归档中核对，系统不按相似日期或轮次猜测。

修改内容、上传或删除本轮附件后，旧结果会提示重新检查；读取期间内容发生变化时也会丢弃过时结果。检查结果只在当前页面暂存，刷新后需重新检查；其他设备更改附件后也应重新检查。“通过”只代表已登记意见的完成／回复状态和分类附件存在，不核验回复质量、文件正文或期刊具体要求，也不代替保存，请先确认云端保存成功后再人工提交。

### 返修截止提醒

论文管线右上角提供“立即保存”，在研、在投、返修、已发表页面共用。点击后会提交尚未结束的行内编辑并显示保存状态：未登录时保存到本机；登录后确认云端同步。失败或离线时会明确提示，不会把本机保存误报为云端成功。现有自动保存仍然保留。

在“论文管线 → 返修论文”把状态选择为“大修改”或“小修改”，即可选择返修截止日期。日期自动保存并显示剩余天数，临近截止与逾期会突出显示；登录后，“概览”同时列出逾期和未来 7 天内截止的返修论文，点击会进入返修模块并定位相应论文。天数按北京时间的日历日期计算。

重投或换期刊后，旧截止日期保留在上一轮投稿历史中，新一轮的截止日期清空。录用、拒稿、撤稿等非返修状态不再提醒。本功能是网页内提醒，不会在关闭网页后发送通知。

### 作者返修清单

在“论文管线 → 返修论文”的卡片中展开“本轮返修清单”，点击“新建审稿意见”，可直接填写审稿意见、修改内容、稿件位置（页码／行号／章节）与回复文字。每条意见可设置为“未处理”“修改中”或“已完成”，完成比例会自动计算。输入内容保存到现有工作区，登录后沿用云端同步，也可使用右上角“立即保存”。

请先填写当前期刊；若曾删除投稿历史，可从返修模块点击“开始返修”建立当前记录，或回到原投稿卡片点击“记录当前投稿到历史”。每次重投或换期刊会使用空白的新清单，旧轮次在返修模块中分别显示。删除一条投稿历史不会删除其返修清单，而是保留在“返修清单归档”；转移到已发表论文后，归档也会保留。删除单条意见需确认。

点击“导出回复清单”可下载该轮的 Markdown 文件，包含填写内容、处理状态与返修截止日期。导出文件可能包含未公开稿件和审稿意见，请妥善保管。本功能用于作者处理自己稿件的返修，与管理他人稿件评审任务的“审稿”模块分开。

已填写审稿意见的未完成条目可点击“加入待办”。需要登录；系统会先保存最新返修清单，再创建带有论文、投稿轮次、意见摘要和该轮截止日期的待办。重复点击或刷新后重试不会重复创建；已存在的待办即使完成也不会被重开。删除待办后可重新加入。

在“待办”中点击“返回返修意见”，会进入“返修论文”、展开对应轮次并定位到该意见。删除投稿历史或论文转到已发表后仍可定位保留的归档；若原意见／论文已删除，会明确提示，待办文字不受影响。待办的完成状态与返修状态独立；截止日期是创建时的快照，之后更改返修截止日期不会覆盖现有待办。

### 按投稿轮次归档材料

在“返修论文”的“本轮材料”中点击“投稿稿”“返修稿”或“回复信”，即可上传、查看和下载该轮对应类型的附件；历史返修轮次及“投稿材料归档”也提供入口。“在投论文”仍保留原投稿稿入口。请先填写当前期刊；若当前投稿尚未记入历史，可点击“开始返修”建立记录，或回到原投稿卡片点击“记录当前投稿到历史”。

重投会使用独立的材料位置，旧轮次不会被覆盖。点击卡片里的“投稿材料归档”可折叠查看已建立的轮次；即使删除一条投稿历史，该轮的材料入口仍会保留。录用后转移到“已发表论文”，材料归档也会一起保留。原先上传的附件仍在“通用与原有附件”里，不会自动重新分类。

附件需要登录，单个文件上限仍为 50 MB，使用原有的账号私有云端空间，无需新增数据库配置。

## 自动保存、同步与备份

- 编辑内容每 3 分钟自动保存；离开页面时，若仍有未保存更改，会提示处理。
- 云端内容按账号同步到其他设备。如果同一账号的本机与云端版本发生冲突，页面会提供选择，并在覆盖前保存冲突副本。
- 点击顶部“数据备份”可导出或恢复账号数据。备份文件可能包含个人研究内容，请妥善保管。
- 点击右上角账号可修改密码或退出登录；修改密码前需要验证当前密码，忘记密码可通过邮箱重置。

## 文献追踪

文献追踪优先从用户填写的期刊官网 RSS / Atom 发现新文章，再用 Semantic Scholar 补充作者与摘要；Crossref 用于 RSS 不可用时的文章发现，并作为 DOI、标题、作者和日期等元数据的后备。摘要与关键词会标注实际来源；Semantic Scholar 学科分类不会伪装成作者关键词。RSS 地址可在添加期刊时填写，也可之后编辑。

首次添加期刊会立即抓取近期文章，之后由 Supabase Cron 每日调用 Edge Function 检查更新。数据库表使用行级安全策略隔离账号数据，定时任务密钥只保存在 Supabase 服务端。独立部署说明见[文献追踪部署说明](docs/journal-tracking.md)。

## 本地运行

仓库仍包含本地 Python 服务。若希望在自己的电脑上运行，可在仓库根目录执行：

```bash
python server.py
```

然后在浏览器打开 <http://127.0.0.1:8765>。仓库保留了本地 Python 服务入口，但当前浏览器版的账号和工作区仍通过 Supabase 登录与同步；仅在本机启动服务不会自动切换成纯本地存储或离线模式。不要在没有 HTTPS 和适当安全配置的情况下把本地服务直接公开到互联网。

## 技术与部署说明

- 浏览器版由静态 HTML、CSS 和 JavaScript 构成，账号与云端工作区通过 Supabase 提供的 Auth 和数据库接口连接。
- 仓库根目录的 `index.html` 是网页入口；GitHub Pages 的实际访问地址以仓库 **Settings → Pages** 为准。
- 若要部署一套独立的在线实例，需要准备自己的 Supabase 项目并配置认证回调地址和工作区数据表；不要把 Supabase `service_role` 密钥放进前端。
- 当前交付形态是网页和本地 Python 服务，不包含可直接安装的 `.exe` 或 `.apk` 安装包。

## 文件附件

知识库文档、研究项目、文献条目以及论文管线卡片可分别上传附件；在研论文的附件也可存放数据、代码与复现材料。文件保存在账号隔离的私有 Supabase Storage 存储桶中，不会塞进工作台正文或浏览器本地存储；同一账号在其他设备登录后可下载。单个文件上限为 50 MB，较大的文件使用可续传上传。删除附件是永久删除，请先确认不再需要。

自行部署时，先在 Supabase 执行 [`supabase/migrations/202609250001_research_attachments.sql`](supabase/migrations/202609250001_research_attachments.sql)，再发布前端。工作台导出的 JSON 备份**不包含附件文件**；请另外备份重要原始文件。附件会占用 Supabase Storage 配额。

## 安卓快捷方式备用入口

如果 Android Chrome 一直停在“安装中”，可打开 [轻量快捷方式入口](https://silencelight-eco.github.io/academic-research-hub/shortcut.html)，从 Chrome 菜单选择“添加到主屏幕／创建快捷方式”。这个入口不声明 PWA 清单，避免触发 WebAPK 打包；它是浏览器快捷方式而不是 APK，仍需网络访问，账号与云端数据和主站共用。
